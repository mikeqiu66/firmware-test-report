# firmware-test-report

固件测试报告 Skill。

## 作用

用于根据固件测试过程资料，生成或更新飞书云文档格式的测试报告。

适用场景：
- 新建某一轮固件测试报告
- 更新已有测试报告
- 根据 ONES 缺陷 Excel 同步报告中的缺陷章节
- 根据已有工时表或手工工时信息补齐测试概要

## 目录

- `SKILL.md`：Skill 主说明
- `references/defect-table.md`：缺陷表参考格式

## 推荐触发方式

直接说下面这类话即可：
- `生成固件测试报告`
- `写第2轮测试报告`
- `更新这个固件测试报告`
- `我发你 ONES 缺陷 Excel，你帮我同步到报告里`

## 使用输入建议

为了减少来回确认，建议尽量提前提供这些信息：

1. 设备名称
2. 固件版本号
3. 第几轮测试
4. 本轮测试起止日期
5. 测试报告链接（如果是更新已有报告）
6. ONES 缺陷 Excel（如果要生成第三章）
7. 工时表链接，或手动工时信息
8. 固件转测单截图（如果要补“修改内容详情”）

## 当前依赖策略

本 Skill 不再硬编码依赖某个固定路径的外部 Skill。

工时相关按下面优先级处理：
1. 先读 `TOOLS.md` 中是否登记了工时表
2. 再读用户直接提供的工时表链接
3. 如果没有可读工时表，则改为让用户手动提供工时信息

## 最小使用示例

### 示例1：新建报告

```text
帮我写 Hub 3 V21.17.17 第三轮固件测试报告，测试时间 2026/05/10-2026/05/14。
```

### 示例2：更新已有报告

```text
帮我更新这个测试报告：https://xxx.feishu.cn/docx/xxxx
本轮测试时间是 2026/05/10-2026/05/14。
```

### 示例3：同步缺陷

```text
我现在发你 ONES 导出的缺陷 Excel，你按这个 skill 更新报告里的缺陷章节。
```
